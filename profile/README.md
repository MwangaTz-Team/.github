### 🌱 Getting Started for Beginners (Wanaochipukia)
New to Git and GitHub? Don't worry, we got you! Here is how you can start your journey with us:
1. **Learn the basics:** Understand how to clone, commit, and push code.
2. **Pick an Issue:** Check out our repositories, look for issues labeled `good first issue`, and try to fix them.
3. **Collaborate:** Always submit your code via Pull Requests (PRs) for review.
